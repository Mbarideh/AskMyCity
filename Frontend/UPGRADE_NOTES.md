# AskMyCity Frontend v3.0

## Highlights
- Premium AI concierge landing page

- Human-friendly radius/search summary

## Run

```bash
npm install
npm run dev
```

The uploaded Windows `node_modules` folder was intentionally removed. Install dependencies locally before running.
